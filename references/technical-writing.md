# 技术写作

模型、数据、工程和实验文本读取本文件，适用于任何语言。目标是让读者直接得到对象、操作、条件、数值和结论。表层语法仍服从目标语言；术语和事实来源仍服从原文与授权材料。

## 句子标准

- 陈述句写全必要语义角色：谁执行了什么操作，操作作用于什么对象，结果在哪些条件下成立。及物动词带上宾语。目标语言允许省略主语时，前文仍要给出唯一、明确的指代。
- 长短句随信息量变化。短句承担明确结论，长句交代条件、方法或限制。连续残句、四字对仗和电报式并列展开为完整句。
- 负面感受或问题判断使用平实语气，直接说明对象、现象与影响。
- 开头直接进入问题、方法或结论。对比关系写成可核对事实；步骤和顺序使用内容词推进。
- 框架编号只在总览出现一次。后续标题使用“长度启发式基线”“结果解读”等内容名称，省略“第一环”“中间两环”这类位置标签。

## 比喻使用条件

技术文本默认使用字面表达。抽象过程、权力关系和心理状态改成可以观察或验证的事实，读者无需把画面还原成机制。

- “吃掉一半空间”写成“已覆盖一半区间”。
- “认题目的检索器”写成“检索器退化为问题识别”。
- “误差范围盖着基准线”写成“置信区间与基线重叠”。
- “多个任务的 Ray 会跟自己撞”写成“多个任务的 Ray 抢占同一端口”。
- “8 个不同血统的模型”写成“8 个使用不同基座的模型”。

成语、常见搭配和“账”字结构同样接受检查。指代完全明确的日常表达可以保留在非技术文本中；技术文本仍优先写出实际对象和动作。新增或强化比喻会改变作者声口时，先向用户确认。

## 八项检查

### 1. 使用标准术语

已有通用术语时沿用通用术语，概念名称在全文保持一致。

| 含混说法 | 技术表达 |
|---|---|
| 超长度 | 是否触及长度上限 |
| 臂 | 方案 |
| 刷奖励 | 奖励值提高，但评测指标未改善 |
| 存档 | checkpoint |
| 只看长度那条线 | 长度启发式基线 |

### 2. 直接说明机制

基座来源、模型数量、覆盖区间、评测口径、截断比例、置信区间等对象使用本领域通行名称。修辞只在原文有意使用且读者无需推断技术对象时保留。

### 3. 使用中性分类名

表头和分类名使用“问题、现象、影响、结果、实验设置、确认程度、重采样后的重合率”等中性名词。章节状态从一套固定标签中选择，例如“已完成 / 已确认 / 未达到基线 / 结论待定”，全文保持一致。

### 4. 直接陈述对比结果

把“是 X，不是 Y”还原成检查结果、指标差异或适用范围。

- “是噪声，不是信号”写成“三项检查结果均在噪声范围内”。
- “考法和用法对不上”写成“评测口径为成对比较，与实际使用方式不一致”。
- “稳定是靠粗糙换来的”写成“取值数量少的指标重合率高”。

当 Y 只是否定性陪衬时，终稿只写 X。“属于噪声，而非有效信号”仍是同一对比结构，应写成“三项检查结果均在噪声范围内”。

### 5. 表格按内容承载信息

一行可以只说明发生了什么，例如“对照组为随机选取的 32 个问题”。数字、判断和结论只在原文提供时出现。

### 6. 标明未知原因

机制尚未确认时写“原因未查明”或“该现象与 X 的关系尚未验证”。前文已经说明未知状态后，后文沿用同一状态。已经验证的机制保留验证范围和条件。

### 7. 使用可复用的技术语体

口语评价改成指标、差值、资源量或直接影响。

| 口语说法 | 技术表达 |
|---|---|
| 赢得很干脆 | 差值为 0.030 |
| 测得糙 | 估计精度更低 |
| 基本等于抓阄 | 接近随机选取 |
| 白跑 / 白占 | 无效运行 / 空占 |
| 不是白捡的 | 需要 79 GPU·小时 |
| 致命问题 | 主要问题 |

数值以原文为准。原文只有定性判断时，终稿继续使用相同强度的定性判断。

“赢得很干脆”一类评价若同时给出差值，直接陈述差值和比较方向。数据已经说明差异时，省略“明显优势”“明确优势”“大幅领先”等评价标签。

### 8. 让技术对象保持技术身份

模型、信号、奖励、截断和答案质量按机制描述。

- “天生需要几百次采样”写成“该信号所需采样量为几百次”；上限以原文数据为准。
- “一旦超就制造出参差”写成“截断发生时会增大奖励方差”。
- “只挪动 0.05”写成“正确率变化为 0.05”。
- “回答好坏参差”写成“答案质量存在差异”。

## 复扫

1. 每个动作都有明确主体和必要宾语。
2. 每个代词都能唯一回指技术对象。
3. 每个数字都来自原文，并保留单位、条件和比较基线。
4. 原因、相关性和因果保持原有证据强度。
5. 表头、状态标签、术语和缩写在全文一致。
6. 读者可以直接复现实验、理解机制或执行操作，无需先解释比喻。
