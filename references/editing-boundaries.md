# 编辑判定边界

只在准备依据 #9–18、#25、#33–36 或 #39–48 修改原文时读取。先按 `SKILL.md` 的语体矩阵选组；本文件只帮助判断“该不该改”和“改到哪里停”，不重新激活被矩阵关闭的规则。

## 使用顺序

1. 先确认目标规则在当前语体中已激活。
2. 指出原文中的具体结构，不能只凭一个词下结论。
3. 用本文件的保护条件反查误判风险。
4. 只做能回指原文的删减、替换或重排。
5. 改完后检查事实、正式程度和原文声口。

本文件中的次数和密度都是操作性启发，不是语料统计或自动判决。除 #47 / #47b 外，单次出现通常不足以触发修改。

## 密度与规则联动

### 同义轮换与指代重复（#9、#36）

同一对象被连续换名，导致读者重新判断指称时，统一称呼。为避免歧义而重复专名、跨段重新点名，或正式文件要求全称时，保留。

- 可改：同一短段把一个产品轮换称作“平台、工具、解决方案、助手”。
- 保留：上一段出现两家公司，下一段用公司全称消除歧义。

不要为了“词汇丰富”主动制造同义轮换，也不要把所有指称机械替换成“它”。

### 空洞并列与否定对举（#10、#48）

先看并列两端是否提供不同信息。两端都只是抽象评价，或用“不是 X，而是 Y”给空概念换名字时，落回原文已有事实。两端承担范围、递进、纠错或法律式排除时，保留结构。

- 可改：“这不只是效率问题，更是认知升级。”原文只有“审批等了两周”时，直接写等待事实。
- 保留：“这不是退款，而是撤销尚未结算的授权。”两端区分不同动作。

#10 与 #48 同时出现时只算一个结构问题，不要重复改两遍。

### `的`、名词化与弱动词（#11、#12、#14、#15）

连续结构让主干难找时再改。先找主语和主要动词；删掉一个“的”、`性`、`化` 或“进行”会改变术语、责任主体、时间关系时，保留。

- 日常表达优先直接动词：“进行了讨论”可改成“讨论了”。
- 学术、公文、法律和技术语体保护稳定术语及必要名词化。
- 不把“兼容性、可用性、初始化、现代化”等规范词拆成生造说法。

### 虚假范围（#13）

检查“从 X 到 Y”是否共享同一尺度或确实覆盖过程。不同层级的概念被硬接成宏大范围时，拆开；真实路线、时间、价格、阶段或职责范围要保留。

- 可改：“从一次点击到整个行业的未来”没有中间关系时，分别陈述。
- 保留：“从提交申请到收到结果用了三天。”

### 破折号解释与破折号密度（#16、#25）

#16 判断单个破折号是否承担了可用逗号、括号或独立句表达的英文式插入；#25 判断整段是否反复依赖破折号推进。两条可同时命中，但只按实际功能改一次。

对话中断、语气突转、范围连接和刻意停顿有明确功能时保留。不要为了消灭破折号把句子改成更多括号或更长定语。

### 中英括注与多余英文（#17、#42）

中文和英文完全重复、目标读者不需要双写时，保留更自然的一种。以下情况保护原文：

- 产品名、协议名、代码、命令、文件名和稳定行业术语。
- 首次出现需要消歧，后文确实使用缩写。
- 用户指定双语、教学、翻译或术语表场景。

先查 `references/whitelists.md`。拿不准时保留，不自行发明译名。

### 列点、列表与表格（#18、#44、#45）

操作步骤、参数对照、责任分工和便于快速比较的数据保留结构。叙事、观点或短答只是为了显得完整而被拆成编号或表格时，恢复自然段。

判断标准是结构是否帮助读者执行或比较，不是列表有几项。把表格改回正文时，不得丢失任一单元格的信息。

### 连接词与节奏（#34、#35）

连接词没有表达真实关系，或每句都用同一种段首词时，删掉空转部分。因果、转折、条件确实存在时保留，必要时换成更直接的句间关系。

节奏调整只允许合并碎句、拆开过长句或改变句式。不要添加新例子、感受或结论来制造“真人感”。

## 汉语语序与翻译残留

### 先找可独立理解的主干（#33）

依次检查：谁或什么、做了什么、对象是什么、条件和时间在哪里。主干被长介词短语、层层定语或重复代词压住时，重排而不改信息。

- 把条件和时间放到动作前后最自然的位置。
- 语境已明确时可省重复主语；有歧义时不要省。
- 被动句能明确受事或责任时保留；整段无必要地连续用“被”才改。
- “作为……”确实限定身份时保留；只充当空开场时删除。

### 心理动作和抽象主语（#39–41）

“接住、击穿、托住、穿透”等词用于真实动作时保留；用于思考、观点或情绪且无法形成自然搭配时，换成原文已有含义的普通动词。

“逻辑很清晰：”“价值很直接：”若只预告下一句，删掉空壳并直接陈述。若形容词本身是用户判断，保留判断，调整承载它的句子。

抽象名词做主语并非自动错误。只有主语连续漂移、读者找不到行动者，或句末只剩空泛形容词时，才把句子落到原文已有的人、事或动作。

## 标点与格式

按功能选择标点，不按个人偏好统一全文：

- 顿号连接词语级并列；逗号分隔分句、状语或较长成分。
- 分号只在并列分句内部已有逗号，或需要显出层级时使用。
- 冒号引出解释、列举或原话；破折号用于突转、插入或强调停顿。
- 括号放不影响主干的补注；补注承担主要信息时改成正文。
- 引号保留原话、特定称谓或确有必要的反讽；不要用引号代替事实核验。
- 省略号只保留真实停顿、省略或未尽语气；不要用来制造深沉。

半角符号在代码、URL、邮箱、版本、文件名和英文中保留。Markdown 只在源码标记意外外露时清理；目标本来就是 Markdown 时，保留结构。

## 事实、占位符与结构

### 抽象占位（#43）

如果 A / B / C 只是作者有意定义的变量、匿名对象或推导符号，保留。若它们假装提供实例却没有对应事实，删除空例子或请用户补充；不能代填。

### 格式残留（#46）

区分“用户需要 Markdown”与“发布正文里意外露出 Markdown”。前者保留，后者只清格式，不顺便改写语言。

### 引用、链接与未填槽位（#47、#47b）

引用和链接必须能回指原文；不能替用户补作者、标题、网址或发布日期。看见 `XX`、`[姓名]`、`某数据`、`待补链接` 等未填槽位时：

1. 保留槽位，不猜内容。
2. 在普通模式标明需要核对；内嵌模式无法安全交付时返回阻塞。
3. 不把占位符误当成可润色的普通名词。

#47 / #47b 是单次即可处理的硬证据，但只授权标记、删除无效引用或请求补充，不授权修复事实。

## 停手检查

准备提交改写前逐项确认：

- 修改依据是具体结构，不是孤立词语。
- 保护条件已经检查，正式语体没有被降成聊天风。
- 标点和语序调整没有改变逻辑关系。
- 列表或表格转换没有丢字段。
- 专名、术语、代码、数字、引用和占位符均可回指原文。
- 同一问题没有被相邻规则重复处理。
- 新句没有加入原文不存在的判断、经历、例子或结果。
