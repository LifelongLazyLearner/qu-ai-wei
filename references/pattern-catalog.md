# 简体中文写作症状目录

本目录是简体中文专层，描述值得编辑的结构，不鉴定文本作者。先判断语义，再看密度、目标语体和信息变化。每个模式都按「骨架 / 触发 / 保护 / 动作 / 复扫」使用；多个模式指向同一问题时合并处理。

证据等级：`中文实证` 表示中文研究直接测量了相应统计特征；`中文研究启发` 表示研究测量了相邻特征，而具体编辑规则属于前向推论；`跨语言研究启发` 和 `平台研究启发` 只提供候选信号；`编辑实践` 表示来自编辑观察或用户偏好。等级限制普遍性声称，保义编辑仍以当前文本为准。

## 1. 内容真实性与具体性

### 低信息密度与篇幅膨胀｜中文研究启发（[CCL 2023 表 2](https://aclanthology.org/2023.ccl-1.46/)）

- 骨架：同一判断换词复述，把一句话摊成多段，解释读者已知的常识。
- 触发：删去句子后只减少篇幅，不减少事实、关系或态度。
- 保护：必要定义、教学分解、风险解释和为不同读者提供的复述。
- 动作：合并重复判断，让事实和动作承担主干。
- 复扫：相邻段是否仍回答同一个问题、得到同一个结论。

### 泛化而缺少细节｜编辑实践

- 骨架：用「相关领域、广泛影响、某种意义、各类场景」回避人物、时间、动作和条件。
- 触发：抽象词取代了原文已有的具体信息，或整段没有可核对对象。
- 保护：原文确实只给出范围判断时，不补造细节。
- 动作：恢复原文已有的人、事、时间和条件；没有细节就收窄说法。
- 复扫：每段是否至少有明确对象或明确限定。

### 无证据拔高｜编辑实践

- 骨架：由普通事实跳到里程碑、时代转折、文化意义、系统性升级。
- 触发：评价超出原文事实支持，或只是重复气势。
- 保护：作者明确作出的评价属于原意，不能删；只重写承载方式。
- 动作：事实先行，评价另放；纯空洞升华可删除。
- 复扫：结尾是否又把局部事件推到宏大尺度。

### 模糊归因、假共识与范围膨胀｜编辑实践

- 骨架：「业内人士 / 研究表明 / 普遍认为」「任何人 / 各种场景 / 从个人到组织」。
- 触发：没有来源，或范围超过原文。
- 保护：真实来源、完整调查范围和必要概括。
- 动作：具体化来源；无法具体化时保留为待核对或收窄范围。
- 复扫：所有归因和全称判断能否回指事实清单。

### 公式化前景、假平衡与正向缝合｜编辑实践

- 骨架：「尽管挑战仍值得期待」「既要 X 又要 Y」「负面事实＋未来可期」。
- 触发：没有真实冲突、条件、行动或态度变化。
- 保护：原文确有权衡、计划或作者态度。
- 动作：写清条件和决策；无信息的乐观结尾删除。
- 复扫：每段和全文结尾是否被统一缝回积极方向。

## 2. 证据、推论与结论强度

### 表面分析与假揭示｜编辑实践

- 骨架：「看似 X，本质 Y」「表面 X，背后 Y」「这说明 / 体现 / 提醒」。
- 触发：X 与 Y 只是两个抽象评价，没有事实建立层次或推论。
- 保护：两项确为作者判断时必须保留含义。
- 动作：让事实先建立关系，再直接写归因或结论。
- 复扫：是否用「真正、其实、深层」换壳继续制造揭示感。

### 推论台阶与连接词链｜跨语言研究启发（[ACL 2024](https://aclanthology.org/2024.acl-long.298/)）

- 骨架：「这意味着→这说明→进一步→由此可见」。
- 触发：连接词增加，信息和证据没有推进。
- 保护：真实演绎步骤、实验推导和必要论证路标。
- 动作：逐步检查蕴含；合并重复结论，保留真实关系。
- 复扫：每个结论是否比前句新增信息，是否超过证据强度。

### 虚构因果、比较与权衡｜编辑实践

- 骨架：时间先后写成因果，不同尺度硬比较，无冲突事项写成平衡。
- 触发：关系无法从原文证据推出。
- 保护：作者明确主张仍属于原意，不能静默改正。
- 动作：能等义就保留并列入 `【需作者确认】`；无法自然保义则暂停。
- 复扫：因果词、比较级和转折两端是否都有依据与共同尺度。

## 3. 篇章组织与信息推进

### 开头复述任务与声明计划｜编辑实践

- 骨架：「基于你的需求」「下面将从三方面」「当我们谈论 X」。
- 触发：正文开始前只复述任务或导演读者。
- 保护：正式摘要、演讲导读、确有导航价值的长文说明。
- 动作：直接进入事实、问题或结论。
- 复扫：删去开场后正文是否完整成立。

### 任意分层与大纲模板｜编辑实践

- 骨架：硬凑三个层面、首先其次最后、每点「标签：解释」。
- 触发：分类混用尺度、项目可合并，或结构不帮助执行和检索。
- 保护：步骤、参数、责任分工、真实分类和长文导航。
- 动作：按读者任务重组为自然段、步骤或真正的层级。
- 复扫：标题和列表是否各自承担不同职责。

### 段落过齐与一段一模板｜跨语言研究启发（[ACL 2024](https://aclanthology.org/2024.acl-long.298/)）

- 骨架：每段同长度、同首句、同一收束，重复“观点—解释—升华”。
- 触发：段落边界服从外观而非信息职责。
- 保护：规范化报告、平行条款和需要快速比较的文档。
- 动作：按事实、原因、限制、行动等职责合并、拆分或调序。
- 复扫：跨段是否仍复述相同主张，段落顺序是否自然推进。

### 收尾复述与统一升华｜编辑实践

- 骨架：「总之」复述全文，再展望、号召或价值拔高；每段以「这说明」封口。
- 触发：结尾没有新结论、决定或下一步。
- 保护：正式摘要、结论章节和用户要求的行动项。
- 动作：停在最后一个有信息的事实、判断或行动上。
- 复扫：段尾和全文结尾是否重复前文。

## 4. 简体中文句法与语序

### 主干后置与前置修饰过载｜编辑实践

- 骨架：「在……背景下 / 基于…… / 通过……」叠加，多层定语后才出现谓语。
- 触发：读者需要回看才能找到谁做了什么。
- 保护：法律、公文、技术定义中承担适用范围的前置条件。
- 动作：先恢复主干，再把时间、条件和范围放到动作附近。
- 复扫：每句能否快速指出行动者、动作和对象。

### 语义角色缺失与电报体｜编辑实践

- 骨架：省略宾语的短动词，如“没打中、懒得接”；四字短语连续对仗；三个问题或动作压成一行快列。
- 触发：读者需要补出行动者、动作对象或因果关系，短句只提供节奏而没有完整命题。
- 保护：对话逐字引语、标题、按钮、日志、状态码，以及目标语言允许且指代唯一的省略。
- 动作：写明谁做了什么、动作作用于什么对象、前后是什么关系。及物动作补齐宾语，短长句按信息量安排。
- 复扫：每个陈述能否独立还原成完整事实；列表中的项目是否仍保持各自关系。

### 翻译式代词、被动与定语链｜编辑实践

- 骨架：重复「它 / 该 / 其」、连续被字句、英语式从句全部塞进定语。
- 触发：指代机械或主干难找，而非单次出现。
- 保护：消歧所需专名、责任明确的被动句、稳定术语。
- 动作：写明必要主语和宾语，拆开定语，恢复自然话题顺序。同一主语连续出现时也要确保每句指代唯一。
- 复扫：主语、谓语、宾语及限定条件是否完整清楚。

### 标点承载结构｜编辑实践

- 骨架：破折号、分号、冒号或括号反复承担本该由句法表达的关系。
- 触发：标点密度和功能单一，换符号仍保留原机械结构。
- 保护：对话中断、真实停顿、并列层级、术语解释和范围连接。
- 动作：先重写句法，再按功能选择标点。
- 复扫：不得只换标点而不改变信息结构。

## 5. 词汇搭配、抽象密度与语义复现

### 词汇与语义复现｜中文实证（[CCL 2023 表 4、表 8](https://aclanthology.org/2023.ccl-1.46/)）

- 骨架：相邻句重复同一名词、动词或评价，或换同义词重说结论。
- 触发：重复不承担强调、消歧或跨段重启作用。
- 保护：关键术语、法律全称、刻意复沓和避免歧义的点名。
- 动作：合并句子、省略已知主语或统一稳定称呼。
- 复扫：既检查同字重复，也检查换词复述。

### 抽象名词化与弱动词｜中文研究启发（[CCL 2023 表 6](https://aclanthology.org/2023.ccl-1.46/)）

- 骨架：「进行 / 实现 / 推动 / 构建 / 体现＋抽象名词」，`性 / 化` 连续堆叠。
- 触发：行动者和动作被埋，删去外壳不损信息。
- 保护：学术、公文、法律、技术中的稳定术语和必要名词化。
- 动作：恢复谁做了什么；不要机械拆术语。
- 复扫：段落主干是否仍由抽象名词和空动词承担。

### 搭配漂移与心理动作直译｜编辑实践

- 骨架：「接住观点、击穿思考、托住情绪」等动作词脱离自然对象。
- 触发：可一对一倒译，且目标语体没有约定搭配。
- 保护：真实动作、行业惯用语、人物声口和品牌语言。
- 动作：换成原文含义内的普通动词，或直接写结果。
- 复扫：不要为了口语化制造另一种生硬搭配。

### 抽象过程实物化、“账”字结构与拟人｜编辑实践

- 骨架：把权力、流程、心理或技术机制写成“卡住、隔着、接管、藏着、靶子、钩子”；把判断写成“心里的账、时间账、还账”；让数据、模型、市场等抽象对象像人一样行动。
- 触发：读者需要先把画面还原成事实，才能知道实际主体、动作或机制。
- 保护：逐字引语、文学叙事、品牌声口，以及指代完全明确的日常表达。
- 动作：直接写出主体、动作、对象、条件和结果。比喻会改变声口时先向用户确认；技术文本按 `references/technical-writing.md` 处理。
- 复扫：每个比喻能否由原文事实直接解释；“账”字是否仍在替代时间、成本、责任或判断。

### 限定词和安全垫串联｜编辑实践

- 骨架：「可能、或许、通常、相对、一定程度上」连续叠加。
- 触发：多个限定表达同一不确定程度。
- 保护：证据等级、适用范围和风险披露。
- 动作：保留最准确的限定，删除重复安全垫。
- 复扫：不得把不确定性清洗成确定判断。

## 6. 修辞、节奏与表现形式

### 对称骨架族｜编辑实践与用户偏好

- 骨架：「不是而是、并非只是、不只 / 不仅……也 / 更、而非、与其不如、看似本质、既是也是更是、从 X 到 Y 再到 Z」。字面连词可以消失，但“先压低一项、再抬高另一项”的关系仍属同一骨架。
- 触发：结构抽象、对称、反复出现，或两端没有新关系。去 AI 味任务中，显眼骨架即使单次也可重写外壳。
- 保护：真实引用、固定定义、事实纠错、范围排除和改变后会歧义的表达。
- 动作：冻结两端含义，改为事实主干、独立句、因果、条件或先肯定后限定。
- 复扫：换成「问题不只在……」「涉及的却是……」「构成……而非……」、分号或同义否定词仍算残留。

### 三连、机械排比与身份升级｜中文研究启发（[CCL 2023 表 6–7](https://aclanthology.org/2023.ccl-1.46/)）

- 骨架：三个形容词、动词、身份或尺度整齐排列，末项继续拔高。
- 触发：项目近义、尺度不同，或只是追求完整感。
- 保护：真实完整清单、步骤、法定要件和有意修辞。
- 动作：合并能落成同一动作层的项目；功能、流程和身份评价属于不同层级时，身份评价另起一句。保留每项断言强度，例如「体现了流程优化」不能加强为「优化了流程」。仅删除「既 / 也 / 更」后把三项留在同一句不算改写。
- 复扫：三项含义是否仍被塞在同一句里。

### 编号化推进与修辞性数字｜编辑实践

- 骨架：“第一环 / 中间两环 / 最后一环”反复代替具体内容；用“365 次公投式”等数字制造规模感，却不表达真实计数。
- 触发：框架已经列过一次，后文仍靠编号推进；数字无法回指事实、单位或计算方式。
- 保护：操作步骤、法定顺序、实验编号、版本号和真实统计数字。
- 动作：框架只列一次，后文用具体内容词指代。事实数字保留单位和条件，修辞数字改成原文实际判断。
- 复扫：读者能否只看内容词理解推进；每个数字能否回指事实清单。

### 句长与句式节奏过齐｜中文实证（[CCL 2023 表 2](https://aclanthology.org/2023.ccl-1.46/)）；跨语言研究启发（[EMNLP 2024](https://aclanthology.org/2024.emnlp-main.368/)）

- 骨架：连续句长度接近、同主语同谓语、每句相同停顿。
- 触发：跨句群观察到模板复现，阅读节奏僵硬。
- 保护：条款、步骤、诗性排比和有意节奏。
- 动作：合并碎句、拆长句、调整信息重心和句序。
- 复扫：不能靠随机标点或口头语伪造变化。

### 预判标签、假口语与礼貌抛光｜编辑实践

- 骨架：「显而易见、值得注意、核心逻辑很清晰、说实话、当然、希望有帮助」。
- 触发：标签不增加证据，态度词不属于作者声口或目标体裁。
- 保护：必要风险提示、真实人物口吻、客服礼貌和演讲互动。
- 动作：删除标签，直接呈现内容；不要硬加第一人称。
- 复扫：结论是否仍由标签代替证明。

## 7. 受众、体裁、平台与交互残留

### 人称与礼貌模板｜平台研究启发（[CCL 2025 图 3](https://aclanthology.org/2025.ccl-1.64/)）

- 骨架：「您 / 你可能 / 大家都 / 希望对你有帮助」机械出现。
- 触发：与目标受众和体裁不符，或泛化第二人称替代具体对象。
- 保护：客服、教程、演讲和真实互动。
- 动作：恢复明确对象或省略无用人称。
- 复扫：不要把所有文本强行改成第一人称。

### 体裁与平台失配｜平台研究启发（[CCL 2025 图 2–3](https://aclanthology.org/2025.ccl-1.64/)）

- 骨架：百科正文带聊天礼貌，报告写成营销稿，教程写成演讲，自媒体机械套平台话术。
- 触发：形式、词汇和互动方式妨碍目标用途。
- 保护：用户指定的平台规范和作者稳定声口。
- 动作：按实际读者任务重建语体、层级和互动方式。
- 复扫：平台特征只在对应平台使用，不推广为通用规则。

### 标题、列表、粗体与表格模板｜编辑实践

- 骨架：每点「粗体标签：解释」、无必要编号、叙事被拆表。
- 触发：格式只为显得完整，不帮助检索、执行或比较。
- 保护：步骤、参数、责任矩阵、数据对照和长文导航。
- 动作：恢复自然段或真正有功能的结构；不得丢字段。
- 复扫：Markdown 是目标格式时保留，不把源码标记本身视为症状。

### 同声引语与伪现场｜编辑实践

- 骨架：所有受访者都使用同样完整、正式的句式，旁白替引语解释情绪。
- 触发：只作为核验提醒，中文证据较弱。
- 保护：真实引语正文绝不擅改。
- 动作：检查来源和周边叙述；无法核验时标记，不改引语内容。
- 复扫：不得为了“更像真人”给引语添加停顿、错字或口头语。

## 8. 来源、引用与事实一致性

### 模型残留、占位符与虚构链接｜编辑实践

- 骨架：知识截止声明、提示词回声、`[姓名] / XX / 待补链接`、虚构 DOI 或网址。
- 触发：单次即可处理，因为它影响可交付性或事实可靠性。
- 保护：教学示例中的变量、真实匿名标记和用户要求保留的模板槽位。
- 动作：保留并要求补充，或删除明确无效的过程残留；绝不代填。
- 复扫：正文、脚注、链接和引用表都要检查。

### 引用绑定与来源漂移｜编辑实践

- 骨架：调序后引文离开支持对象，来源被写成支持更强结论，多个来源混成一个共识。
- 触发：文内陈述和来源之间不再一一对应。
- 保护：默认不承担外部真伪核验。
- 动作：引用与被支持陈述一起移动；收窄到来源实际支持的范围，或列入核对。
- 复扫：逐条确认数字、引语、归因和结论的来源绑定。

## 来源与引用边界

- [CCL 2023 表 2、表 4、表 6–8](https://aclanthology.org/2023.ccl-1.46/) 直接测量篇幅、句子数、段落数、句长标准差、词汇多样性、相邻句 / 全文重复、并列短语、短语类型和衔接重复。“更长、节奏变化较小”和复现属于直接统计信号；文本冗余、“三连”“弱动词”等具体编辑规则仍是推论。
- [CCL 2025](https://aclanthology.org/2025.ccl-1.64/) 图 2–3 比较微博评论中的长度、规范标点、情感词和平台互动标记；只支持平台敏感性，不证明所有中文都应删除人称、礼貌或规范标点。
- 跨语言结构研究：[EMNLP 2024](https://aclanthology.org/2024.emnlp-main.368/) 测量生成文本的句法模板，[ACL 2024](https://aclanthology.org/2024.acl-long.298/) 研究篇章 motif；二者只提供迁移线索，具体中文改写规则仍需前向测试。[ACL 2025](https://aclanthology.org/2025.acl-long.267.pdf) 只作为人工判断线索的补充。
- 中文编辑观察：[维基百科《AI 生成文的特征》](https://zh.wikipedia.org/wiki/Wikipedia:AI%E7%94%9F%E6%88%90%E6%96%87%E7%9A%84%E7%89%B9%E5%BE%B5)，页面明确是描述而非规定，维基专属规范不转成通用规则。
- 身份检测边界：[GPT detectors are biased against non-native English writers](https://arxiv.org/abs/2304.02819/)。模式目录只服务编辑，不服务作者身份判断。
